## Visit labor included in actual service cost (94b52c7)

**Report:** SO-2609-06984 showed two visit-labor entries—46 hours at $45/hour
and 46 hours at $65/hour—but Actual Service Call Cost omitted both.

**Cause:** visit labor is stored in `job.visitLabor`, while the shared cost
helper only read baseline contractor pay and Parts & Labor line items.

**Fix:** the shared cost calculation now adds every priced visit-labor entry
once across all visits. The breakdown identifies visit labor alongside base
and extra labor. Unpriced visit hours remain operational records and add $0.

**Verified live:** sha `94b52c7`, build
`v1.7.6.3+94b52c7.1789565388867`. SO-2609-06984 now shows $5,160 labor

$6,380 Actual Service Call Cost. The API handler returned its expected 401 for
an unauthenticated request. Build and all 1,000 tests passed; production UI
