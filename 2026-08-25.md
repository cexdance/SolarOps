# 2026-08-25

## Service Orders board redesign (05046d9)

Shipped a full layout rebuild of the admin Service Orders kanban, drafted first
as a design canvas and then implemented in `Jobs.tsx`.

**Live:** v1.7.6.2+05046d9, builtAt 2026-08-25T04:06:35Z. `/api/users` returns
401 (not a Vercel NOT_FOUND page), so the serverless functions built.

### What changed and why

Five concrete problems, all visible in the pre-change catalog screenshot:

1. **Columns were `flex-1 min-w-[280px]`.** flex-grow stretched four columns
   across the viewport and clipped the fifth at the screen edge. Now a fixed
   `w-[218px] shrink-0`: five columns visible at 1440, the rest scroll.
2. **The control bar was three stacked rows** (view toggles / filter row /
   search) costing ~214px before the first card. One row, 52px. The board now
   starts about 130px higher, roughly one more card per column.
3. **Cards carried four colored pills with no hierarchy** (status, quote,
   priority, equipment). Priority is now a dot, work type and assignee are
   monochrome glyphs, PowerCare is a bolt beside the order number, and the
   single status pill is the only badge left.
4. **Names and addresses clipped mid-word.** The badge stack moved off the right
   rail onto the identity row, which freed the full card width, so `truncate`
   became a two-line `line-clamp-2` with `overflow-wrap: anywhere`.
5. **`Sort: Default` was repeated in every column header** (7 copies on the
   board, 14 on LL). One board-wide sort now drives the list view and every
   column; `columnSortBy` state is gone entirely.

Also: Hold/Resume became icon-only PauseCircle/PlayCircle buttons with the name
in `title` + `aria-label`, and the three filter toggles became icon+count chips
named On Hold / PowerCare / Archive.

### Patterns worth reusing

- **`formatMoney` is a policy gate, not a formatter.** With `SHOW_MONEY` off it
  returns `-`, so the card footer had been rendering a bare dash on every card
  for as long as the flag has been off. It now renders only when the value is
  real. This is the third time this gate has bitten; see the Billing notes.
- **A `//` comment cannot live inside a JSX opening tag.** Caught before the
  build, but it is a silent-looking edit that breaks the parse.
- **Raw markup cannot pass through a Design Component `{{hole}}`** (holes render
  as escaped text). Bind a single SVG `d` path string to an attribute instead.
  Relevant to the canvas, not the app.
- **Verify a board change against the capture script, not by reasoning.** The
  first pass looked right in code and had three real defects in the screenshot:
  the sort control had wrapped to a second row (defeating the whole point of the
  change), order numbers broke across two lines, and the meta row truncated.
  All three were only visible in the PNG.

### Follow-ups

- LL column titles truncate at 218px ("Leads Services Sol..."). Full name is on
  hover via `title`; a two-line header would be better if it annoys anyone.
- The card no longer shows a total. That is `SHOW_MONEY` being off, not a
  regression, but it means the board carries no money signal at all right now.
- The canvas and the code diverge in one place on purpose: the artboard shows an
  "On Hold" pill on held cards, the code keeps the real pipeline status pill
  instead (the On Hold column and the green Resume button already carry hold).
